本站本身

聽寫俠是純靜態網頁：沒有帳號、沒有後端伺服器、沒有資料庫、不使用 Cookie 與任何分析追蹤。你的文字與歷史記錄只存在你自己瀏覽器的 localStorage，清除瀏覽器資料即完全刪除。

引擎一：瀏覽器內建辨識

使用瀏覽器（Chrome/Edge）內建的 Web Speech API。你的語音會經由瀏覽器送往其語音服務（Google）進行辨識——這是瀏覽器內建功能的行為，不是本站控制。麥克風權限由瀏覽器管理，可隨時收回。在意錄音外流者請改用本機引擎。

引擎二：本機 Whisper

AI 模型下載後完全在你的瀏覽器內執行：錄音與轉錄過程不會上傳到任何伺服器。模型檔案來自公開的 CDN（jsDelivr／Hugging Face），下載行為僅取得模型本身。

引擎三：自帶 API

錄音檔會直接從你的瀏覽器送至你自己設定的 API 端點（例如 OpenAI）。金鑰只存在你的瀏覽器。該服務如何處理你的音檔，適用其隱私政策，請自行查閱。

外部資源

本頁載入 jsDelivr CDN 的開源程式庫；使用本機引擎時會從 Hugging Face CDN 下載模型。這些請求由 CDN 服務商記錄 IP 等技術資訊。

GDPR 歐盟資料保護權利

若你位於歐洲經濟區（EEA）、英國或瑞士，依《一般資料保護規則》（GDPR）你享有下列權利：

  • 存取權：可要求我們提供所持有之個人資料副本。
  • 更正權：可要求更正不正確或不完整的個人資料。
  • 刪除權（被遺忘權）：可要求刪除你的個人資料。
  • 資料可攜權：可要求以機器可讀格式取得你提供給我們的資料。
  • 反對與限制處理權：可對基於正當利益（含分析統計）之處理提出反對或要求限制。
  • 撤回同意權：基於同意之處理（如分析 Cookie）可隨時透過 Cookie 偏好設定或清除網站 Cookie 撤回同意。
  • 申訴權：可向你所在地的資料保護機關提出申訴。
