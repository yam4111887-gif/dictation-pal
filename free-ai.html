免費 AI 額度總整理＋BYOK 指南

整理日期：2026 年 8 月 ｜ 各平台免費額度隨時調整，申請前以各官網最新說明為準
這篇的立場很簡單：拒絕月費綁架，但走合法路線。網路上有「破解版」「共享帳號」甚至把訂閱轉 API 的灰色工具——那些違反服務條款、帳號隨時會被封。下面整理的是官方自己提供的免費額度，用得心安理得。

主流免費額度（依「可用率」排序）

  • Google AI Studio／Gemini API——免費層最慷慨的主流選項：網頁版 AI Studio 直接用，API 免費額度足夠個人專案（有速率限制）。適合：問答、翻譯、長文件。
  • Groq——超快推論＋免費 API 額度（開源模型如 Llama 系列）。適合：要速度的應用。
  • Mistral（La Plateforme）——免費層可用其模型 API。適合：歐系模型的替代選擇。
  • OpenRouter——聚合器，標示哪些模型有免費額度（free 標籤），一個金鑰用多家。適合：不想申請一堆帳號。
  • Cloudflare Workers AI——開發者向的免費額度（每天定量推論）。適合：自建小工具。
  • 本機模型（完全免費、離線）——Ollama 跑對話模型、Whisper 跑語音轉錄（我們的聽寫俠「本機引擎」就是這個）。適合：隱私優先、不想被額度綁住的人。

BYOK：把免費額度變成「你自己的訂閱」

BYOK（Bring Your Own Key，自帶金鑰）是省錢的核心招：申請上述任一家的免費 API 金鑰，填進支援 BYOK 的工具——工具免費、額度免費，你只花自己的流量。我們的兩個工具都吃這套：

  • 聽寫俠：「自帶 API」引擎填入 OpenAI 相容端點（許多免費額度服務都提供 OpenAI 相容格式），語音轉錄用你自己的額度
  • Resume Preflight：履歷匹配分析的 API 金鑰存在你自己瀏覽器，分析次數無限制、零月費

三個省錢原則

  1. 能本機就本機：語音轉錄、摘要這類任務，本機模型品質已夠用——零成本＋隱私。
  2. 免費額度多家輪用：不同家的額度互不影響，重度使用者可以兩三家輪流。
  3. 看清楚條款：免費額度多半限制商用或速率；個人使用通常無虞，商業應用前讀一下條款。

誠實提醒

免費額度的品質與穩定度不如付費；重要的商業用途，付一點錢買穩定是合理的。這篇反對的是「用不到那些功能卻被綁月費」，不是反對付費。
