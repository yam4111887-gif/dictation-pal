BYOK：把免費額度變成「你自己的訂閱」

BYOK（Bring Your Own Key，自帶金鑰）是省錢的核心招：申請上述任一家的免費 API 金鑰，填進支援 BYOK 的工具——工具免費、額度免費，你只花自己的流量。我們的兩個工具都吃這套：

  • 聽寫俠：「自帶 API」引擎填入 OpenAI 相容端點（許多免費額度服務都提供 OpenAI 相容格式），語音轉錄用你自己的額度
  • Resume Preflight：履歷匹配分析的 API 金鑰存在你自己瀏覽器，分析次數無限制、零月費

三個省錢原則

  1. 能本機就本機：語音轉錄、摘要這類任務，本機模型品質已夠用——零成本＋隱私。
  2. 免費額度多家輪用：不同家的額度互不影響，重度使用者可以兩三家輪流。
  3. 看清楚條款：免費額度多半限制商用或速率；個人使用通常無虞，商業應用前讀一下條款。

誠實提醒

免費額度的品質與穩定度不如付費；重要的商業用途，付一點錢買穩定是合理的。這篇反對的是「用不到那些功能卻被綁月費」，不是反對付費。
